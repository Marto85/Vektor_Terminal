# Manual de Usuario

## Descripción General
Este software permite visualizar los estados financieros estandarizados de empresas públicas estadounidenses sin necesidad de carga manual. 

## Búsqueda de Empresas
1. Ingrese el Ticker de la empresa (ej. `MSFT` para Microsoft, `AAPL` para Apple).
2. El sistema consultará automáticamente el CIK asociado en la base de datos de la SEC.
3. Se descargarán los datos financieros históricos completos y se unificarán en una vista estándar (Cuenta de Resultados, Balance, Flujo de Efectivo).
